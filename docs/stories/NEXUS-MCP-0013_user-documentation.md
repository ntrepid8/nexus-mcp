# NEXUS-MCP-0013: Basic User Documentation (Installation & Setup)

## Description
Create comprehensive documentation for users to install, configure, and connect Nexus MCP to their preferred AI agents (Gemini CLI and Claude Code).

## Requirements
- Provide a `README.md` or a dedicated `docs/setup.md` with step-by-step instructions.
- Detail the installation of dependencies (`npm install`).
- Explain how to configure environment variables (e.g., `NEXUS_REMOTE_URL`, `NEXUS_DATA_DIR`).
- Provide specific configuration snippets for:
    - **Gemini CLI:** How to add the server to the `.geminirc` or equivalent config.
    - **Claude Code:** How to add the server to the `claude-code` config.
- Include a "Troubleshooting" section for common Git and connection issues.

## Dependencies
- NEXUS-MCP-0001: Initial Project Scaffolding
- NEXUS-MCP-0003: Local Directory Git Initialization & Remote Configuration
